GZ COMPTA — VERSION ANDROID / MOBILE

Cette archive contient la version mobile/PWA basée sur la dernière version multi-sites GZ COMPTA.

CONTENU
- www/index.html : application GZ COMPTA
- www/manifest.webmanifest : installation comme application Android lorsqu'elle est hébergée en HTTPS
- www/sw.js : cache hors connexion
- www/icon-192.png et icon-512.png : icônes Android

INSTALLATION SUR ANDROID
1. Héberger le dossier www sur un serveur HTTPS (ou sur votre serveur central).
2. Ouvrir l'adresse dans Google Chrome sur Android.
3. Menu ⋮ > Installer l'application / Ajouter à l'écran d'accueil > Installer.
Google indique qu'une web app peut être installée depuis Chrome et apparaître comme une application sur Android.

IMPORTANT
Cette archive est la version Android/PWA prête à être déployée. Elle n'est pas un APK signé Google Play.
Le logiciel conserve les données localement comme dans la base GZ COMPTA actuelle. La synchronisation centrale doit pointer vers le serveur réellement déployé.
